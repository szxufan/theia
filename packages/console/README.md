## 描述

`@theia/console` 扩展提供一个 `console`（控制台）组件，用于在调试时求值表达式（以 REPL [(Read-Eval-Print-Loop)](https://en.wikipedia.org/wiki/Read%E2%80%93eval%E2%80%93print_loop) 的形式）。
