## 描述

`@theia/ai-huggingface` 将 Hugging Face 的模型与 Theia AI 集成。
Hugging Face API 密钥和要使用的模型可以通过首选项进行配置。
或者，也可以通过 `HUGGINGFACE_API_KEY` 环境变量提供 Hugging Face API 密钥。
