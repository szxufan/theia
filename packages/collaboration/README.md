## 描述

`@theia/collaboration` 扩展提供在使用 Theia 的多个对等端之间进行协作的功能。
它构建在 [Open Collaboration Tools](https://www.open-collab.tools/)（[GitHub](https://github.com/TypeFox/open-collaboration-tools)）项目之上。

请注意，该项目仍处于 beta 阶段，可能会出现意想不到的破坏性变更。因此本包同样处于 beta 阶段。
