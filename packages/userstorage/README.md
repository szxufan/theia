## 描述

`@theia/userstorage` 扩展提供访问用户存储文件的 API，例如首选项、自定义快捷键映射及其他用户专属文件，而无需了解其实现细节。用户存储文件可以通过 `userstorage` URI 协议访问，例如 `userstorage://settings.json`，用户存储服务的实现会据此获取相应的文件。
