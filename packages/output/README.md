## 描述

`@theia/output` 扩展为应用程序贡献一个 `output`（输出）组件，向最终用户显示输出内容。
所显示的输出通常来自后端执行的外部命令，例如 `git` 或语言服务器（language-server）。
一般而言，与日志消息相比，输出通常需要用户投入更多注意力，因为它们往往更冗长，
并且有助于识别内部操作——当出现问题时，用户可以针对这些操作采取行动。
