## 描述

`@theia/markers` 为给定文件增加对文件标记（诊断标记（`errors`、`warnings`、`infos`、`hint`））的支持。
该扩展提供以下内容：

- `problems view`（问题视图）：一个专用视图，用于查看由语言服务器、lint 工具、任务问题匹配器为工作区贡献的诊断标记
- `marker decoration`（标记装饰）：基于标记装饰应用程序不同组件的能力（例如：文件资源管理器）
