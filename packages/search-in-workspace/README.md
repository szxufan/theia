## 描述

`@theia/search-in-workspace` 扩展提供了使用不同搜索技术对给定工作区中所有文件执行搜索的能力。

## 搜索组件

`@theia/search-in-workspace` 扩展提供了 `Search`（搜索）组件，能够执行多种类型的搜索，包括：

- 执行标准搜索
- 使用正则表达式执行搜索
- 在 `include` 列表内执行搜索（搜索特定类型的文件，例如 `*.ts`）
- 排除文件或目录执行搜索（使用 `exclude`）
- 忽略隐藏或已排除的文件/文件夹执行搜索
- 执行搜索并替换（快速更新搜索词的多个出现位置）
